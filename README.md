## 🏆 Featured Projects

### 🔥 **RailRoute** - A modern Indian train tracking app.

[![Live Link](https://img.shields.io/badge/🌐_Live_Link-4285F4?style=for-the-badge)](https://railroute-tau.vercel.app/)
[![GitHub](https://img.shields.io/badge/💻_Source_Code-181717?style=for-the-badge&logo=github)](https://github.com/Harsh-Gharewal/RailRoute/)

**📝 Description:**  
🚆 RailRoute — A modern Indian Railways train tracker with live GPS tracking, interactive maps, delay analytics, route elevation, terrain & POI intelligence, station weather, and offline train search.

**🚀 Key Features:**

- 🚆 Live Train Tracking: Track real-time train locations and status.
- 🗺️ Interactive Maps: Explore train routes using MapLibre maps.
- 🔍 Fast Train Search: Quickly find trains with offline search support.
- 📱 Responsive Design: Seamless experience across desktop and mobile devices.

**💻 Tech Stack:** Next.js • TypeScript • TailWind • Framer Motion • Zustand • API Integration

### 🔥 **DocPilot** - RAG Pipeline with Hybrid Search Over Internal Docs

[![GitHub](https://img.shields.io/badge/💻_Source_Code-181717?style=for-the-badge&logo=github)](https://github.com/Harsh-Gharewal/DocPilot/)

**📝 Description:**  
🔍 DocPilot is a production-ready RAG platform that uses hybrid search (Dense Vector + BM25), Reciprocal Rank Fusion, and Cross-Encoder Reranking to deliver accurate, context-aware answers with source citations and hallucination control.

**🚀 Key Features:**

- 📄 Multi-Format Ingestion: Processes PDF, Markdown, TXT, and HTML documents.
- 🔍 Hybrid Search: Combines ChromaDB and BM25 using Reciprocal Rank Fusion.
- 🎯 AI Reranking: Improves retrieval accuracy with Cross-Encoder reranking.
- 🛡️ Grounded AI Responses: Delivers cited answers with confidence scoring and hallucination prevention.

**💻 Tech Stack:** Python • FastApi • Streamlit • ChromaDB • OpenAI • Matplotlib • Docker
